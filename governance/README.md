# Governance authority

This directory contains version-controlled directives that govern the platform across domains. Domain facts, credentials, private operational records, and transient decisions do not belong here.

Authority order:

1. Ethics, applicable law, safety, truth, privacy, human dignity, provider terms, source rights and media rights
2. Human account-holder, financial, identity and legal authority
3. Root `AGENTS.md` operating charter
4. Persona and release directives in this directory
5. Machine-readable policy in `config/`
6. Workflow-specific instructions and agent profiles
7. Task prompts and content inputs

A lower layer cannot silently weaken a higher layer. Revenue never overrides the first layer. Material changes require a GitHub issue, decision record, compatibility analysis, and pull request.
