## Corrections prepared here

1. Distinct public empty, private preview, and unavailable states; readers are not told to restart local services or operate the content studio.
2. Independent feed/video/image loading with bounded request timeouts; an optional image or card endpoint failure does not suppress otherwise available videos.
3. Reactions acknowledge only accepted HTTP responses. Comments retain their text when acceptance is uncertain, and requests are not automatically retried.
4. Dependency-free JavaScript regression checks in CI and Python tests for the Hosting asset contract.

These changes improve failure handling. They do not invent approved content, relax source rights, waive publishing consent, or make the application commercially complete.
