# Version 1 release candidate notes

Version: `1.0.0-rc.1`. Snapshot date: 2026-09-13.

## Purpose

This release candidate freezes the first coherent implementation of the BS CATS reusable intelligence platform and the SmartGlasses pilot. It replaces the earlier “bootstrap edition” description with explicit architecture, authority, requirements, release, cost, and GitHub change-control boundaries.

## Included

- Four-persona authority model and ethics-first operating purpose
- Governed object, evidence, semantic and feedback foundations
- Domain-portable configuration and smart-glasses ontology
- Solo operator and audience applications
- Bounded agent and deterministic tool harness
- Rights-aware media catalog and local kinetic-video pipeline
- Exact approval and multichannel distribution packaging
- Firebase, Firestore, Storage, BigQuery and Cloud Run deployment definitions
- GitHub issue and pull-request operating process
- Requirements and release-readiness audits

## Not claimed

This release does not claim a production cloud application, populated warehouse, reconciled spend, rotated credentials, legally cleared media library, approved public video, successful social publication, measured revenue, or autonomous policy self-improvement.

## Compatibility

Version 1 preserves the existing local object format and application routes. Ontology standards alignment is additive; it does not migrate current objects to RDF or require a graph database. Inactive worker shells remain outside the production topology.
